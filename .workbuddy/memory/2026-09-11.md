# 2026-09-11 工作日志

## 任务：S2C-Net 在 Ubuntu(CUDA 12.2) 上的部署方案梳理

### 仓库结构要点
- 工作区根 = 项目根，但内部有两层同名嵌套：
  - 代码根目录 `S2C-Net/S2C-Net/`（`train.py` 在此，**训练必须在此目录下执行**）
  - SAM2 仓库根 `sam2-main/sam2-main/`（`pip install -e .` 在此执行）
- `sam2/sam2_hiera_{t,s,b+,l}.yaml` 是**伪配置**：内容只有一行字符串
  `configs/sam2/sam2_hiera_l.yaml`，不是真正的 YAML 配置。

### 实测确认的三个阻塞问题及修复
1. **Hydra 配置路径错误（必须改 `Model.py`）**
   sam2 的 `sam2/__init__.py` 执行 `initialize_config_module("sam2", version_base="1.2")`，
   Hydra 搜索路径 = sam2 包目录本身。
   实测 `compose(config_name="sam2_hiera_l.yaml")` → `{'configs/sam2/sam2_hiera_l.yaml': None}`，
   无 `model` 节点 → `instantiate(cfg.model)` 必崩。
   改为 `configs/sam2/sam2_hiera_l.yaml` → 实测可解析出
   `cfg.model._target_ = sam2.modeling.sam2_base.SAM2Base`，`trunk.embed_dim = 144`。
2. **`RSOC.py` 只支持 Synthetic**
   - `.mat` 键名：`Synthetic/Se*` → `sub_points`(复数)；`Real/*` → `sub_point`(单数)。
   - 原代码仅在 `name.startswith("Se")` 时赋值 `keypoints`，其余文件名 → `UnboundLocalError`。
   - 列索引 `[:, [2,3]]` = (x, y)，与原实现一致，无需改动。
3. **无预训练权重**，且配置与权重必须成对（v1.0 配 v1.0）：
   v1.0 配置 `add_tpos_enc_to_obj_ptrs: false` → `obj_ptr_tpos_proj = Identity`（无参数）；
   SAM2.1 配置 `proj_tpos_enc_in_obj_ptrs: true` → 该层变成 `Linear`。
   混用会在 `_load_checkpoint` 的严格 `load_state_dict` 处报 missing/unexpected keys。

### 数据集实测统计（`TMS Data.zip`，313 MB，18477 条目）
- 结构为 `TMS Data/{Real,Synthetic}/<scene>/<name>.jpg` + 同名 `.mat`（图像与标注同目录）。
- 总计 9296 jpg / 9152 mat。差额 144 = **`Synthetic/Se9/` 全部无标注**，必须剔除。
- Real 12 场景 / 7336 张；Synthetic 14 场景（Se1–Se8, Se11–Se15）/ 1816 张；合计 9152 张。
- 图像尺寸仅两种：512×512（6480 张）、480×540（2816 张）；短边最小 480 > crop_size 256，
  不会触发 `assert st_size >= self.c_size`。
- 基名跨场景唯一，无需重命名。

### 环境版本决策
- Python 3.10；`torch==2.5.1` + `torchvision==0.20.1`，**索引必须 `.../whl/cu121`**。
  驱动最高 CUDA 12.2 → cu124 需驱动 ≥ 550.54.15 会报 insufficient；cu121 最低驱动 530.30.02，满足。
- SAM2 用本仓库自带 v1.0，editable 安装并 `SAM2_BUILD_CUDA=0`（CUDA 扩展只服务推理期掩码后处理，
  `sam2/utils/misc.py:61` 的 `_C.get_connected_componnets`，训练不需要）。
- 已验证可下载：`torch-2.5.1+cu121-cp310-linux_x86_64.whl`(744 MB)、
  `sam2_hiera_large.pt` v1.0 `072824`(856 MB)，均 HTTP 200。
- 训练器 `assert self.device_count == 1` → **仅支持单卡**；`--wandb 0` 仍会 `wandb.init(mode="disabled")`，
  故 wandb 必须安装。
